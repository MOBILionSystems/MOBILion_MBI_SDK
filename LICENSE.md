The MBI-SDK Development Kit ("MBI-SDK") comprises a Microsoft Windows 64-bit dynamic load library, or DLL, and supporting libraries that provide read capability of MBI data files produced by the MOBIE® EyeOn software acquisition system. The kit also includes library documentation and example code that demonstrates use of the libraries. The MBI-SDK contains Microsoft Windows C++ Dynamic Load Libraries that provide interfaces for reading meta-data, mass spectral data, and ion mobility data acquired through use of MBI instruments. The libraries also provide interfaces for obtaining calibrated data that may be used to transform raw data stored in a MBI data file into correctly calibrated units.
