Compute the CCS reduction factor (1/Z) * sqrt(m_gas * m_ion / (m_ion + m_gas)) used to convert between CCS and reduced CCS. Throws if Z, M_ion, or the resulting factor would be non-positive.

Parameters
M_ionIon m/z.
ZIon charge state (must be strictly positive).
Note
Virtual so NonReducedEyeOnCcsCalibration can override it to 1.0; the base AT<->CCS methods dispatch through this, so overriding it suffices to disable reduction.
