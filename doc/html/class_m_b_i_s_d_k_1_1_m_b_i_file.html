◆ ExperimentType

enum class MBISDK::MBIFile::ExperimentType
strong

Experiment types represented by a MBI file. /summary>

Enumerator
MS1 

An MS1 experiment. Note that if collected on MOBIE with a MassHunter method with fragmentation turned on this can be AIF.

AIF 

AIF data collected through EYEON, as e.g. the high-energy file for stiteched (MIFF) MAF.

SIFF_MAF 

MAF with a single input file.

MIFF_MAF 

MAF stitched from two input files.
